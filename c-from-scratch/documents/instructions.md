# C From Scratch Instructions

This folder is organized to match the style of `cpp-from-scratch`: numbered topic folders first, supporting documents and resources after that.

## Conventions

- Numbered folders follow the learning order.
- Lesson notes live inside the matching topic folder.
- Example programs live in the topic's `examples/` folder.
- C source files use lowercase kebab-case with an order prefix, for example `01-first-program.c`.
- Existing compiled binaries and data files were preserved during organization.
- The current clean roadmap lives at `resources/roadmaps/01-core-c-roadmap.md`.

## Current Layout Notes

- `01-c-basics/examples/` contains the original first-program examples.
- `02-control-flow/` contains both original control-flow markdown files plus the original examples folder.
- `03-arrays-strings/` combines the old arrays examples with both array and string notes.
- `08-file-handling/` contains the original file-operation examples and data files.
- Empty folders such as `09-data-structures/` and `10-advanced-c/` are placeholders from the roadmap.
